Elden Ring Inspired Cursor Pack

A fan-made Windows cursor pack inspired by the visual style of **Elden Ring**.

The project started with an Elden Ring-style pointer created by **THTH** and published on RealWorld Designer. That pointer was used as the starting point for the project, after which the rest of the cursor set was created and adapted to form a complete Windows cursor pack.

The goal was to keep the visual language of the original pointer while extending it to the standard Windows cursor states.

## Features

- Complete Windows cursor set
- Elden Ring-inspired visual style
- 32×32 cursor graphics
- `.cur` and `.ani` Windows cursor formats
- Automatic installation and uninstallation scripts
- No executable files
- No changes to Elden Ring or its game files

## Included Files

### Cursors

- `eldenarrow.cur` — Normal Select
- `eldenbusy.ani` — Busy
- `eldendiagonal1.cur` — Diagonal Resize
- `eldendiagonal2.cur` — Diagonal Resize
- `eldenhorizontal.cur` — Horizontal Resize
- `eldenlink.cur` — Link Select
- `eldenmove.cur` — Move
- `eldenprecision.cur` — Precision Select
- `eldentext.cur` — Text Select
- `eldenunavailable.cur` — Unavailable
- `eldenvertical.cur` — Vertical Resize
- `eldenwait.ani` — Working in Background

## Installation

Run `Install.bat` as administrator.

The script installs the cursor files and registers the cursor scheme with Windows.

After installation, select the cursor scheme in:

**Windows Settings → Bluetooth & devices → Mouse → Additional mouse settings → Pointers**

Then apply the installed scheme.

## Uninstallation

Run `Uninstall.bat` as administrator.

The script removes the cursor files and the cursor scheme installed by this project.

## How the Cursors Were Made

This is a cursor-design project rather than an application, so there is no traditional source code or buildable executable.

The cursor graphics were created/adapted manually using **RealWorld Cursor Editor** and exported to standard Windows cursor formats.

The project workflow was:

1. Use the original Elden Ring-style pointer by THTH as the visual starting point.
2. Create/adapt the remaining Windows cursor states around that pointer.
3. Keep the cursor dimensions and visual style consistent.
4. Export the cursor designs to `.cur` and `.ani` formats.
5. Create Windows installation and uninstallation scripts.
6. Package the finished cursor set for distribution.

The repository contains the resulting cursor files and installation scripts so the contents of the released pack can be reviewed directly.
